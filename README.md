## 🌟 简介

基于 Hugo + PaperMod 的个人技术博客，托管于 GitHub Pages。分享技术笔记、项目经验和编程心得。

## 🚀 特性

- 📝 技术文章 & 随笔
- 🗂️ 文章归档
- 🚀 项目展示
- ⭐ 星标项目（含时间线）
- 🔗 友链申请
- 📱 响应式设计
- 🌙 深色/浅色主题切换
- 🤖 自动化部署 & 星标同步

## 🛠️ 技术栈

- **静态网站生成器**: Hugo
- **主题**: PaperMod
- **部署**: GitHub Pages
- **CI/CD**: GitHub Actions
- **域名**: zephyr-rain.me

## 📁 项目结构

```
Yzeph.github.io/
├── .github/
│   ├── ISSUE_TEMPLATE/      # Issue 模板（友链申请等）
│   └── workflows/           # GitHub Actions 工作流
├── content/
│   ├── posts/               # 博客文章
│   ├── projects/            # 项目展示
│   ├── about/               # 关于页面
│   ├── links/               # 友链页面
│   ├── archives.md          # 归档页面
│   └── stars.md             # 星标项目页面
├── layouts/                 # 自定义布局
├── themes/PaperMod/         # 主题（子模块）
├── config.yaml              # 网站配置
└── 文件架构                  # 项目结构说明
```
